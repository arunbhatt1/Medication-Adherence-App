📱 Medication Adherence App
A Flutter-based Medication Adherence Application designed to help patients manage their medications effectively while allowing caregivers to monitor adherence remotely. The app supports role-based access for Patients and Caregivers, ensuring proper medication tracking and supervision.

🚀 Features
👤 Patient Module
Secure login and registration using Firebase Authentication

Add medication details such as:

Medication name

Dosage

Reminder time

View a list of added medications

Data stored securely in Firebase Firestore

🧑‍⚕️ Caregiver Module
Secure caregiver login

View medications added by assigned patients

Monitor patient medication data remotely

🔐 General Features
Role-based navigation (Patient / Caregiver)

Cloud-based data storage using Firebase

Cross-platform support (Android, iOS, Web)

User-friendly and simple UI

🛠️ Tech Stack
Frontend: Flutter (Dart)

Backend & Database: Firebase Firestore

Authentication: Firebase Authentication

Platforms Supported:

Android

iOS

Web
